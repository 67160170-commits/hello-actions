Hello GitHub Actions

โครงงานฝึกพัฒนาและเผยแพร่เว็บไซต์ด้วย JavaScript ตั้งแต่การเขียน tests ไปจนถึงการนำเว็บไซต์ขึ้นใช้งานผ่าน GitHub Pages

ดูซอร์สโค้ดบน GitHub ↗ ดูผลการตรวจสอบ ↗

กระบวนการเผยแพร่เว็บไซต์

  1. ส่งการเปลี่ยนแปลงพัฒนาโค้ดและเปิด Pull Request
  2. ตรวจสอบอัตโนมัติรัน tests บน Node.js 22 และ 24
  3. เผยแพร่หลังผ่านการตรวจสอบMerge เข้า main แล้วอัปเดต GitHub Pages

องค์ประกอบของโครงการ

01 / TESTING

ทดสอบการทำงาน

ตรวจสอบฟังก์ชันคำนวณ การเรียงข้อมูล การทำงานแบบ async และการตรวจจำนวนเฉพาะ

02 / QUALITY

ควบคุมคุณภาพโค้ด

กำหนด coverage ขั้นต่ำ 80% และตรวจสอบหลายเวอร์ชันก่อนอนุญาตให้รวมโค้ด

03 / DELIVERY

เผยแพร่อย่างเป็นระบบ

ใช้ GitHub Actions เผยแพร่เว็บไซต์ พร้อมแยกค่าตั้งค่าและข้อมูลลับออกจากซอร์สโค้ด
